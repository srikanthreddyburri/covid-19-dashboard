# covid-19-dashboard
This Tableau dashboard provides an interactive visualization of the COVID-19 pandemic in India. 
It is designed to help users analyze and interpret key trends, patterns, and statistics related to the spread of COVID-19, vaccination rates, and recovery rates across different states and time periods.
Features:
1)State-wise Analysis:
   View the total number of confirmed cases, recoveries, and fatalities for each state in India.
   Identify hotspots with the highest number of active cases.
2)Trend Analysis:
   Observe the progression of COVID-19 cases over time with line charts and bar graphs.
   Compare daily new cases, recoveries, and deaths.
3)Vaccination Insights:
Analyze the vaccination coverage across the country.
   Track the percentage of the population vaccinated in each state.
4)Recovery and Fatality Rates:
   Explore recovery and fatality rates to assess the healthcare system's efficiency in handling the pandemic.
Tools and Technologies:
   Data Source: Official COVID-19 statistics sourced from government records or other reliable repositories.
   Visualization Tool: Tableau.
   Data Preprocessing: Performed using Excel for cleaning and preparation.
